**Date:** 2026-11-03
**Auditor:** Senior Full-Stack / Firebase (automated)
**Status:** Read-only audit; no code changes made in this pass.

## 1. Framework & Dependencies

- Astro `^7.4.4` (static output), `@astrojs/sitemap` `^3.7.4`
- Node 22 (CI). ESM (`"type": "module"`).
- Firebase `^13.1.0` (client), `firebase-admin` `^14.5.0` (scripts)
- cheerio, fast-xml-parser, fuse.js, nodemailer, dotenv

## 2. Architecture

- Frontend: Astro file-based routing, single `BaseLayout`, global CSS (no UI framework).
- Backend: Firebase (Auth + Firestore + Hosting). Server scripts (Node ESM) run in GitHub Actions.
- Data: static JSON generated by `scripts/build-*.mjs` from catalog/sources; ingested pending queue synced to Firestore; approved jobs pulled back to `data/jobs.json`.

## 3. Firebase Configuration

- Project: `followupdates` (number 454412451234).
- Hosting: serves `dist/`, trailingSlash true, cache + security headers.
- Firestore: rules (admins allow-list, public read published jobs, owner-only profiles), composite indexes for jobs/pending/subscribers.
- Auth providers enabled: Email/Password, Phone. **Google NOT enabled** (gap).
- Authorized domains: localhost, followupdates.firebaseapp.com, followupdates.web.app.

## 4. Authentication System

- `src/lib/auth.ts`: Google popup, email/password sign-in+sign-up, phone OTP (RecaptchaVerifier), sign-out, onAuthStateChanged, updateProfile.
- `AuthGate.astro`: client-side gate; signed-out → `/login/?next=...`.
- Admin: checks `admins/{uid}` doc; no role tiers.

## 5. Firestore Collections

- `admins` (doc per admin UID)
- `pending` (scraped updates; status pending/approved/rejected)
- `jobs` (published updates)
- `users` (profile `users/{uid}`)
- `users/{uid}/saved` (saved job IDs)
- `subscribers` (email/telegram; active flag)

## 6. Existing Admin Panel

- Tabs: Pending (search/category filter), Published, Add manually.
- Actions: approve (pending→jobs, marks approved), reject, unpublish (delete jobs doc), manual publish.
- No dashboard analytics, no role tiers, no content scheduling, no automation control.
